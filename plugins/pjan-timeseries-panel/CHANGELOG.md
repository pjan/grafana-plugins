# Changelog

## 1.0.0 (unreleased)

- The field config refresh after switching a core Time series panel to this plugin in the panel editor (`fieldConfigRefresh`) moved to the workspace package `@pjan/grafana-panel-utils`, shared with the other plugins in the repository. No change in behaviour. `THIRD_PARTY_NOTICES.txt` lists the package.
- **Threshold lines** (opt-in): Threshold line color, Threshold line opacity and Threshold line width in Thresholds, right after Show thresholds and shown when it draws lines; per series by override. A shade of each threshold's colour (Softer … Stronger, the colour Grafana draws the line in, the transparent rule included) or one fixed colour; an opacity that replaces the colour's own; a width in pixels, multiplied by the pixel ratio and drawn crisp (dashes keep Grafana's length). They apply to the lines Grafana draws, one set per axis, of the first series on it whose Show thresholds isn't Off (hidden series included); a line Grafana draws fully transparent stays hidden. Unset, the panel draws as core. The shared slider editor saves a picked value equal to the unset value it shows (`unsetIsExact: false`).
- **Colours for lines, fills and points** (opt-in): Line color, Fill color and Point color in Graph styles, each right under the core option it refines (Line width, Gradient mode, Point size) and shown only where it changes the drawing; per series by override. A shade of the series colour (Softer … Stronger, ranked by contrast with the panel background), Series color (fill and points), or a fixed colour; fill opacity and the Opacity and Hue gradients apply to the fill colour; the legend, the tooltip and an axis in the series colour show the line colour, and a colour picked in the legend is drawn as picked. Ignored with by-value colour schemes, and (line and fill) with the Scheme gradient. Unset, the panel draws as core.
- Port of Grafana's core time series panel from grafana/grafana v13.2.3, meant as a drop-in replacement: same options, defaults, presets, migrations, rendering and interaction. The end-to-end suite compares it with the core panel (canvas bytes, every element and attribute, screenshots) in the light and the dark theme, after a live theme switch, and at pixel ratio 1 and 2; what has passed is recorded in `UPSTREAM.md` ("Test runs"). Panel suggestions are left off; long data shows core's message, and in the panel editor its actions without "Transform to wide time series format"; the Grafana Assistant tooltip button is pruned. Switching a core Time series panel to **Time series plus** in the panel editor keeps every option, the field config, the overrides and the colour scheme. See `UPSTREAM.md` for what was copied, changed, and left off.
- Scaffolded with `@grafana/create-plugin` 7.11.0 and set up as a workspace of this repository, with the build, test and licence configuration of the other plus plugins.
