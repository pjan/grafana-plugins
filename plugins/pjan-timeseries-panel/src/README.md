# Time series plus

Grafana's time series panel, as a separate panel plugin: planned as a drop-in replacement for the core **Time series** panel of Grafana 13.2.3, starting from Grafana's own code, with opt-in additions.

**Not ready for use.** This version is a placeholder (the plugin template's sample panel); the port of the core panel is in progress.

## Source code

https://github.com/pjan/grafana-plugins (`plugins/pjan-timeseries-panel`)
