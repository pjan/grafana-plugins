# Changelog

## 1.0.0 (unreleased)

- **Text weight** (opt-in field option in Cell options, after Text color; with it unset nothing changes and nothing new is saved): Regular (400), Medium (500) or Semibold (600), saved as a number (`custom.styling.textWeight`), for the text of Colored text, Colored background and Pill cells (on a row colored by Apply to entire row, the row field's own cells only) and of Tooltip from field. Automatic text is measured at it (no color changes at table sizes). Wrapped rows and content-aware column widths are measured at the weight, so heavier wrapped text is not cut off. Its select is the clearable select shared with State timeline plus (`@pjan/grafana-styling`). Grafana loads Inter at 400 and 500 only: browsers draw 600 as an emboldened 500, so there is no 700 (it would draw the same).
- **Pill options and the Pill look** (opt-in; with none set nothing changes and nothing new is saved). Four field options in Cell options, after Text color, for Pill cells only: **Pill fill color** (a shade of the pill's color, or fixed), **Pill line color** (a shade, or fixed: a line inside the pill's edge), **Pill line width** (1–3 px) and **Pill corner radius** (0–12 px). Each changes only its own part: a line color alone draws a 1 px line, a line width alone draws it in the pill's color, and on a transparent pill the line replaces Grafana's border. A panel option, **Look** (Grafana or Pill, after core's Table options), as in State timeline plus: Pill fills the pill options left unset with the Softer fill, a Base 1 px line and Automatic text. Where Table plus draws the pill's fill, an unset Text color is Automatic on it. Translucent pills on a row colored by Apply to entire row are now measured against the row's fill (with Text color too). String-hash pills take their nearest hue's shades. Saved as `custom.styling.fillColor`, `lineColor`, `lineWidth`, `cornerRadius` and `styling.look`.
- **Text color and Background color** (opt-in field options in Cell options, right after Cell type; with neither set nothing changes and nothing new is saved). **Background color** (a shade of the value's color, or a fixed color) fills Colored background cells and, with Apply to entire row, the row; on gradient cells a shade keeps Grafana's gradient, built from the shaded color, and Fixed applies to basic cells only. **Text color** (Automatic, Value, a shade, fixed) colors the text of Colored background cells (and the row), Pill cells and Colored text cells. Automatic is the first readable shade of the fill's hue (4.5:1, 3:1 for large text, at least 4.2:1 where a shade reaches it), against both colors of a gradient (where no shade reaches 4.2:1 on both, the color with the highest contrast on both, which can be as low as about 3.2:1: use basic mode where text must be readable); on Colored text, of the value's color against the table's background, a colored row's fill or the tooltip's background. Unset text is Automatic on a Background color, Grafana's own otherwise. Colors without a name take their nearest hue's shades; a continuous color scheme is shaded per color and keeps its transition. Saved as `custom.styling.backgroundColor` and `custom.styling.textColor`. Bundles `@pjan/grafana-styling`.
- Port of Grafana's core table panel (v13.2.3) and the `TableNG` component it renders: with nothing set, Table plus looks and behaves like core Table (options, defaults, the load migration, every cell type including geo cells, colours, sorting, filtering, column widths, pagination, footer, cell inspect, data links and actions, tooltips from fields, nested tables, the frame picker). Bundles the grid (`@grafana/react-data-grid` 7.0.0-beta.57) and the table's other dependencies at the versions Grafana 13.2.3 uses; OpenLayers (10.7.0) is loaded only for tables with geometry fields. Switching a core Table panel to Table plus in the panel editor keeps its options, field config, overrides and colour scheme. Suggestions are left off.
- Set up as a workspace of this repository (scaffolded with `@grafana/create-plugin` 7.11.0), with the build, test and licence configuration of the other plus plugins. The table feature flags (`table.autoColumnWidths`, `table.paginationPageSize`) are read as core reads them, through Grafana's public OpenFeature provider proxies (bundles `@openfeature/web-sdk` 1.9.0), and only for a signed-in user, as in core. A lint and build check guards against imports of `@grafana/ui/unstable` and the `/internal` entry points.
